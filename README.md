# PIML_Project
Code and data used for PIML Final Project - Spring 2025

Organization as follows:

Data: Data from each subject, including raw data and processed data used for the CNN. See README in that folder for more information.

Pre-Processing: Matlab file and function for pre-processing (filtering) data and creating CSVs. GRF_compute function is used to compute the reaction force of the foot on the ground for the external torque term.

Figures: 
  code_generating: Contains code to generate figures and raw files to edit to produce figures. 
  complete: contains final figures found in paper

CNN_model: Contains colab script in python to run CNN model. See README in that folder for more information.

Physics: Contains matlab code for buildind and testing physical model of leg dynamics.
